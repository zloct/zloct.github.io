欢迎来到我的博客！这是使用 Hexo 搭建、托管在 GitHub Pages 上的第一篇文章。

## 这个博客是怎么搭起来的

- **框架**：[Hexo](https://hexo.io/)，基于 Node.js 的静态博客框架
- **主题**：[Butterfly](https://github.com/jerryc127/hexo-theme-butterfly)
- **托管**：GitHub Pages，每次推送代码自动构建发布

## 以后会写什么

1. 学习笔记
2. 项目记录
3. 生活随笔

## 写作方式

所有文章都是 Markdown 文件，放在 `source/_posts/` 目录下。新建一篇文章只需要：

```bash
hexo new post "文章标题"
```

然后推送代码，GitHub Actions 会自动构建并发布，无需手动操作。
